| Action | Windows and Linux | macOS |
| --- | --- | --- |
| Open **Settings** | `Ctrl+,` | `⌘ ,` |
| Enter or exit full screen | `F11` | `Ctrl+⌘ F` |
| Restore a maximised tile | `Esc` | `Esc` |

## In the right-click menu

| Key | Action |
| --- | --- |
| `↓` and `↑` | Move to the next or previous item |
| `Home` and `End` | Move to the first or last item |
| `Enter` or `Space` | Choose the item |
| `Esc` or `Tab` | Close the menu |

## With the mouse

| Action | Result |
| --- | --- |
| Double-click a tile | Maximise it, or restore it when it is maximised |
| Right-click a tile | That camera's menu, then the wall's |
| Right-click the wall | The wall's menu |
| Move the pointer | Shows the toolbar with **Edit layout** and **Settings** |
